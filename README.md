# Tuk-Track API

Sri Lanka Police Three-Wheeler (Tuk-Tuk) Tracking & Movement Logging System

## Student ID
COBSCCOMP242P-022 

## Description
A RESTful API built with Node.js, Express, and MongoDB for real-time tracking of registered three-wheelers across Sri Lanka.

## Tech Stack
- Node.js / Express
- MongoDB Atlas / Mongoose
- JWT Authentication
- Swagger UI
