## Description
A RESTful API built with Node.js, Express, and MongoDB for 
real-time tracking of registered three-wheelers across Sri Lanka 
for law enforcement use.

## Tech Stack
- Node.js / Express
- MongoDB Atlas / Mongoose
- JWT Authentication
- Swagger UI / OpenAPI 3.0
- Deployed on Railway
